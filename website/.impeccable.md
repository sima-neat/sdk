## Design Context

### Users
System engineers using Modalix and Palette SDK to package signed eLxr images
and work with the kernel, device trees, boot chain, and other system software.
Application development belongs at https://developer.sima.ai/software.

### Brand Personality
Clean, technical, readable. Match the existing SiMa Neat documentation style,
as confirmed by the user. Match the corporate palette from releases.neat.sima.ai/brand.css and sima.ai: blue #5998DD, text blue #346CA9, green #2A9C4F, lime #A4CC2D, purple #4A4276, and orange #D26728. Help developers act with confidence.

### Aesthetic Direction
Systems Builder Guide: a standalone Docusaurus site with SiMa branding, restrained blue
accents, generous reading space, clear command examples, and light/dark support.
No developer-portal shell or navigation integration yet.

### Design Principles
- Lead with the next practical task and runnable commands.
- Separate application development in SDK from image assembly in PIB.
- Publish only explicitly selected customer-facing documents.
- Preserve commands and technical meaning across all five languages.
- Keep navigation accessible on mobile and with the keyboard.
