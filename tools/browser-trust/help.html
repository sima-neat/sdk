Certificate help

The editor may open before your browser trusts this SDK’s HTTPS certificate, but extension panels need that trust to load.

Install this public CA certificate on the computer running your browser, not on the remote SDK host.

Download CA certificate

Only install it if you trust the SDK host. This computer will trust certificates issued by that development CA. The download contains no private key.

  1. Save sima-sdk-rootCA.pem in Downloads.
  2. Open Keychain Access, select the System keychain, and import the file. Double-click the certificate, expand Trust, and set Secure Sockets Layer (SSL) to Always Trust. Close and authenticate.
  3. Fully quit your browser (⌘Q), reopen this address, and sign in.
Use Terminal instead

  1. Download the certificate.
  2. Press Win + R, run certmgr.msc, and open Trusted Root Certification Authorities → Certificates. Select Action → All Tasks → Import, choose the downloaded PEM file (select “All files” if needed), and complete the wizard.
  3. Close all browser windows, reopen this address, and sign in.
  1. Download the certificate to your Linux browser computer.
  2. In Chrome, open Settings → Privacy and security → Security → Manage certificates. Import the file as a trusted website authority in the local/custom certificates section. Labels vary by distribution and browser version.
  3. In Firefox, use Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import and enable trust for identifying websites.
  4. Restart your browser, reopen this address, and sign in.
